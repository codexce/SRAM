Design of 64-bit Storage Cells Using 8T SRAM 
•	Role: Lead VLSI Architect 
•	Tech Stack: Cadence Virtuoso, CMOS Technology, SRAM Design, Low-Power VLSI 
•	Led the design and implementation of a high-performance 64-bit SRAM storage system using 8T memory architecture for improved stability and reduced leakage power. 
•	Developed and simulated the memory cell layout in Cadence Virtuoso, ensuring optimal transistor sizing for power and speed trade-offs. 
•	Implemented customized read/write assist circuits to enhance operational reliability under varying supply voltages. 
•	Conducted comparative analysis with conventional 6T SRAM, demonstrating superior noise margin and reduced read disturb issues.
